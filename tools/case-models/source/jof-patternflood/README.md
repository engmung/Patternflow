# Patternflood's cut files, for its 3D model

`patternflood.py` builds the /build page's model of Patternflood from these: one DXF per laser-cut part of the box, millimetres, every part drawn as seen from outside the box, compensated for 3.18 mm birch and a 0.15 mm kerf. They are copies, kept here so the model is made from files in this repository like every other case's. The box itself, its build guide, the nested cut sheets, the etched art and its software are in [jof/patternflood](https://github.com/jof/patternflood); change them there, and copy the DXFs here again.
